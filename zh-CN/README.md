# 药水永续（PotionPermanent）

当背包或随身存储中同一效果的药水 / 食物达到指定数量时，其增益效果永久保持；并带一个增益控制器。

## 功能

- 背包、猪猪存钱罐、保险箱、保卫者熔炉、虚空保险库中的同款消耗品累计达到阈值后，对应增益永久生效
- 永久生效期间增益图标不显示倒计时（与篝火、心灯一致）
- 食物类增益自动保留最高等级（完美饱食 > 大饱食 > 饱食），互不冲突
- 酒类（麦酒、清酒）带来的「微醺」同样可永续；真正有害的减益不会被永续
- 阈值默认 30，可在游戏内 F6 → 配置 里改成 1–999
- 数量掉回阈值以下后，已生效的增益会在时间耗尽后正常消失

## 增益控制器

左键点击左上角增益栏里的任意增益图标，打开增益控制器面板：

- 面板里按顺序列出当前生效的增益，悬浮显示增益说明
- **左键**：开启 / 关闭该增益。关掉的增益立刻消失，并且之后不会再被补上（包括便携工作站、时装增益等其它来源给的增益），图标显示为变暗 + 红框
- **Alt + 左键**：收藏该增益，收藏的会排到最前面（金色边框）
- 面板底部「全部开启」按钮用于一次性清除所有被关掉的增益
- 面板可拖动，Esc 或右上角 × 关闭；下次打开时回到上次的位置
- 开关状态与收藏保存在 `TerrariaModder\mods\potion-permanent\buff-controller.json`

蜡烛类便携增益：水蜡烛等家具的增益由场景统计决定，而便携类模组是在扫描结束后才把数量补上的，导致增益点不亮。
开启「便携蜡烛增益」后模组会把这一步补上，于是随身带水蜡烛就能真正亮起增益，也能在控制器里开关。

## 配置

在游戏内模组菜单 →「配置」页修改（实时生效），文件保存在 `core/configs/potion-permanent.client.json`：

| 配置项 | 说明 |
| --- | --- |
| 总开关 | 药水永续功能总开关 |
| 生效数量 | 触发永续所需的最小数量（默认 30） |
| 增益控制器 | 点击左上角增益图标打开控制面板 |
| 便携蜡烛增益 | 让随身携带的水蜡烛等蜡烛增益真正生效 |
| 调试日志 | 输出调试日志 |

## 说明

- 存储位置任意（背包或随身容器）都会计入数量
- 数量低于阈值后，已生效的增益会在其时间耗尽后正常消失
- 增益控制器对勾选开关以外的增益不做改动；关掉的减益也会被移除
