# Potion Eternity (PotionPermanent)

A potion's or food's buff is kept permanently once you stock enough of the same item.

## Features

- Once the combined stack of matching consumables in your inventory, Piggy Bank, Safe, Defender's Forge or Void Vault reaches the threshold, that buff becomes permanent
- Permanent buffs show no countdown on the buff icon (same as the Campfire and Heart Lantern)
- Food buffs keep only the highest tier (Exquisitely Stuffed > Plenty Satisfied > Well Fed), so they never conflict
- The threshold defaults to 30 and can be set to 1-999 in game via F6 -> Config
- If the amount drops back below the threshold, the buff expires normally when its timer runs out
